# Live EKS deployment evidence — 2026-08-31

This record captures the first end-to-end deployment of KubeVista to AWS. It
is operational evidence, not a claim that the intentionally ephemeral demo
environment remains online.

## Provisioning result

- AWS Region: `us-west-2`
- EKS cluster: `kubevista-dev`, Kubernetes `v1.36.3-eks-cb19647`
- Terraform result: `92 added, 0 changed, 0 destroyed`
- Network: three public, three private, and three control-plane subnets across
  three Availability Zones; one internet gateway and one cost-optimized NAT
  gateway
- Compute: two private managed nodes, both `Ready`, with no node-group health
  issues
- Controls: KMS envelope encryption, EKS control-plane logs, VPC flow logs,
  restricted `/32` API access, IAM Identity Center access entry, AWS Budget,
  Pod Identity, PDBs, HPAs, and NetworkPolicies
- Native add-ons: VPC CNI, CoreDNS, kube-proxy, EBS CSI, and EKS Pod Identity
  Agent
- Teardown deadline recorded by the guarded workflow:
  `2026-09-01T05:30:53Z`

All Kubernetes API `readyz` checks passed, including etcd, KMS providers,
admission initialization, informer synchronization, storage readiness, and
API aggregation.

## Production defects found and corrected

The live deployment exposed four integration defects that repository-only
validation could not reproduce:

1. Kubernetes could not verify the distroless image's named `nonroot` user.
   Commit `5a18c84` pins UID and GID `65532` while preserving
   `runAsNonRoot` and the read-only root filesystem.
2. OpenTelemetry SDK default resources and a hard-coded semantic-convention
   schema conflicted at process startup. Commit `44f26e8` uses schemaless
   service attributes and adds a regression test.
3. Hardened Nginx required writable runtime scratch space. Commit `1595fce`
   mounts a size-limited, memory-backed `/tmp` while keeping the root
   filesystem read-only.
4. The lightweight OTel Kubernetes distribution lacked the configured
   Prometheus exporter. Commit `d16d656` moves the gateway to the official
   contrib distribution; both replicas then reported ready pipelines.

CI passed for each corrective commit. The final platform run was
[`33454660572`](https://github.com/andy98w/Kubernetes-Dashboard/actions/runs/33454660572).
